# Contextual compute and the tool offer

Status: `proposed`. The full argument is in [the Loom note](https://github.com/siliconcordat/loom/blob/main/docs/08-contextual-compute.md). This file states only what Layer 5 owns. It does not change the zone manifest, the five-verb contract, or the prose gate.

The broker is the open pathway set the session may touch. A closed tool is absent from the offer. It is not listed and then refused after the model has considered it. Syntax zone tags stay the names of pathways at the text level.

The adaptive parameter field in the Loom note decides the offer before a task starts. `mde` enforces that offer. It does not invent the field.
